# Yiming Zhu — Personal Homepage

A static academic homepage ready for GitHub Pages.

1. Create a public repository named YOUR-GITHUB-USERNAME.github.io.
2. Upload the extracted files directly to the repository root. index.html must be at the top level.
3. Open Settings > Pages. Under Source select Deploy from a branch. Choose main and /(root), then Save.
4. Open the site URL shown in the Pages settings after deployment completes.

Edit personal information, publications and teaching records in app.js. Edit visual styling in styles.css.

GitHub documentation: https://docs.github.com/en/pages/quickstart
